This is a CSS Grid behavior where items in a row span the full row height.

**Investigation needed:**
1. Find how widgets are laid out in Dashboard.jsx
2. Look for the grid container structure
3. The current layout likely uses a single grid with col-span values

**Potential fixes:**

Option A - Use separate rows:
Instead of a single grid, split into explicit rows:
```jsx
<div className="space-y-3">
  {/* Row 1: Status Cards + Today */}
  <div className="grid grid-cols-4 gap-3">
    <div className="col-span-3">{/* Status cards */}</div>
    <div className="col-span-1">{/* Today */}</div>
  </div>
  {/* Row 2: Recent Activity + Weight */}
  <div className="grid grid-cols-3 gap-3">
    {/* widgets */}
  </div>
</div>
```

Option B - Use CSS Grid subgrid or grid-template-rows:
```jsx

```

Option C - Use flexbox for rows:
Wrap widgets in flex containers per row.

**Investigate the current structure first, then apply the appropriate fix.**

- Older activity from `last_activity` endpoint may have reptile ID but not full data

**Fix approach:**
Create a reptile lookup map at component mount, then ensure all activity items have avatar data:

```jsx
// If using a reptile map:
const reptileMap = useMemo(() => {
  const map = {};
  reptiles.forEach(r => {
    map[r.id] = r;

  return map;
}, [reptiles]);

// When building activity items:
const enrichedActivity = activity.map(item => ({
  ...item,
  reptile: item.reptile?.avatar_photo_url
    ? item.reptile
    : { ...item.reptile, avatar_photo_url: reptileMap[item.reptile?.id]?.avatar_photo_url }
}));
```
