## Decisions Made

**1. Consecutive-miss logic instead of time-based:**
- More forgiving than Duolingo's daily streak
- Breaks only after 2 consecutive missed tasks (not 1 day without activity)
- Resets counter to 0 on any completion

**2. Freeze days for vacation protection:**
- Tasks still due, notifications still fire (streak protection only)
- Manual freeze: 1-day emergency use
- Scheduled freeze: deduct days upfront, refund if cancelled before start

**3. Milestone rewards:**
- 7 days → 1 freeze day
- 30 days → 2 freeze days
- 100 days → 3 freeze days
- 365 days → 5 freeze days

**4. Only manual-completion schedules count:**
- Auto-complete schedules excluded from streak calculation
- Prevents gaming the system with automatic completions

**5. Shared responsibility credit:**
- Any co-responsible user's completion credits all co-responsible users
- Encourages collaboration in multi-user households
